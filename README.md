# Music Canvas（音乐艺术屏）· B1 封闭测试版

原生 Android 的“音乐视觉伴侣”。它显示并控制你正在用的音乐 App（网易云、QQ 音乐等）里播放的内容，本身不是播放器：没有曲库、不下载歌曲、不处理音频。

## 构建

要求：JDK 17、Android SDK 34、Gradle 8.9（AGP 8.5.2 / Kotlin 2.0.21）。

```bash
gradle :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk（applicationId com.musiccanvas.app.debug）
```

依赖仓库优先使用阿里云镜像（Maven Central 会返回 429）。minSdk 30（Android 11）、targetSdk 34。

## B1 功能清单

| 模块 | 内容 |
|---|---|
| Demo 模式 | 没有授权也能体验；有“演示”标识，不会把示例数据当成真实数据 |
| 授权引导 | 说明后跳转到系统“通知使用权”页；在系统设置里撤销授权后立即回到 Demo（通过 ContentObserver 监听） |
| B0 媒体会话层 | NotificationListenerService + MediaSessionManager；会话代际号和曲目代际号用来防止串源，过期的封面加载结果会被丢弃 |
| 来源选择 | 来源白名单；“固定来源”（默认）和“自动跟随正在播放的来源”两种模式；状态胶囊显示来源 App 名称 |
| 字段降级 | 缺少歌手、时长或封面时不报错；显示“来源仅提供部分信息”；没有封面时用曲名生成占位封面 |
| 控制 | 上一首 / 播放暂停 / 下一首，根据来源声明的能力决定是否可用（不支持就置灰）；指令只发给当前绑定的来源 |
| 进度 | 根据 PlaybackState 的位置、更新时间和倍速每秒推算；来源不提供进度时隐藏进度条 |
| T01 暖木黑胶 | 唱片旋转，暂停时唱臂抬起，封面嵌在唱片中心，主色从封面取（Palette） |
| T02 留白封面 | Pro 主题，B1 期间免费体验 |
| 动效档位 | 标准 / 节能 / 静态；支持“隐藏曲目信息（纯艺术）” |
| 桌面展示模式 | 全屏常亮；定时 15/30/60 分钟后自动退出；控制栏自动隐藏，点一下唤出；支持横竖屏 |
| 设置 | 桌面定时、断开并清除允许来源、清除偏好、隐私说明、版本信息 |
| 权益结构 | 预留 `EntitlementStore` 接口；B1 使用 `FreeBetaEntitlementStore`，所有主题解锁，不接任何真实支付 |

隐私方面：不申请 INTERNET、麦克风、无障碍或悬浮窗权限；歌曲信息只保存在内存里，不写盘、不上传。

## 已知限制

- **没有在真机或真实音乐 App 上测试过。** 网易云音乐、QQ 音乐、Spotify 等 App 实际提供哪些字段、支持哪些控制，以及各家 ROM（MIUI / ColorOS / HarmonyOS 等）的后台限制和通知使用权行为，都还没验证，**目前不能声称兼容**。建议封测第一周用真机跑 PRD 里的兼容矩阵。
- 部分国产 ROM 会杀后台或回收通知监听服务，可能需要引导用户设置“自启动 / 电池无限制”。这部分 B1 没有实现。
- 进度是推算出来的，来源跳转进度却不更新 PlaybackState 时会有偏差。
- 没有接入真实支付。R1 需要接入 Google Play Billing 或国内应用商店的支付，并实现 PRD MC-060..064 的验单、恢复购买和撤销逻辑。
- 只构建了 debug 包，没有签名的 release 包；正式发布前需要准备 keystore、开启 R8 混淆，并做软著和应用商店备案。
- B1 范围之外的功能不做：歌词、频谱、BPM、麦克风、悬浮窗、锁屏替换、AI 等。

## 目录
